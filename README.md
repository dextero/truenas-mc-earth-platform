# Earth Platform TrueNAS App Catalog

This is a custom TrueNAS SCALE app catalog for [Earth Platform](https://github.com/pirut/earth-platform) - the real Earth in Minecraft at true scale for NeoForge 1.21.1.

## Usage

Add this repository as a custom catalog in TrueNAS SCALE:
1. Go to Apps > Manage Catalogs > Add Catalog
2. Set Repository URL to this git repository
3. Set Train to `community`
4. Install Earth Platform from the catalog

## App Location

The Earth Platform app is located at `ix-dev/community/earth-platform/`.
