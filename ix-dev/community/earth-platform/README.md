# Earth Platform

[Earth Platform](https://github.com/pirut/earth-platform) is the real Earth in Minecraft at true scale for NeoForge 1.21.1.

This uses the itzg/minecraft-server image with TYPE=NEOFORGE, VERSION=1.21.1, and requires the Earth Platform mod jar to be placed in the mods folder. Follow the [installation guide](https://github.com/pirut/earth-platform/blob/main/docs/INSTALL.md) to get the mod jar.
